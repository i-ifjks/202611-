# 施工体系図 公開サイト

倉敷市水島地区公共施設再編整備事業 水島中学校テニスコート整備工事の施工体系図を、スマートフォンから閲覧できる静的サイトです。

## ファイル

- `index.html`：公開ページ
- `chart.pdf`：掲載中の施工体系図（2026年11月版）
- `styles.css`：表示デザイン
- `qr.html`：サイト公開後に現場掲示用QRコードを作成するページ

## 公開方法（GitHub Pages）

1. GitHubで新しい**Public**リポジトリを作成します（例：`mizushima-taiseitai`）。このPDFは公開資料として全員が閲覧・保存できます。
2. このフォルダ内のファイル一式をリポジトリの最上位にアップロードして、変更を保存します。
3. GitHubのリポジトリで **Settings → Pages** を開き、公開元に `Deploy from a branch`、ブランチに `main`、フォルダに `/(root)` を指定して保存します。
4. Pagesに表示された実際の公開URLを開いて、ページとPDFが見えることを確認します。URLはリポジトリ名や所有者によって変わるため、この一式では仮のURLを設定していません。
5. 同じ公開サイトの `qr.html` を開き、実際の公開URLを入力してQRコードを作成・保存し、読み取り確認後に掲示してください。

GitHub Pagesの公開URLは通常 `https://<アカウント名>.github.io/<リポジトリ名>/` です。`<...>` は実際の値に置き換わります。

## 毎月の更新

1. 新しい施工体系図PDFの内容・公開可否を確認します。
2. リポジトリ内の `chart.pdf` を新しいPDFで置き換え、同じファイル名で保存します。ファイル名を固定することで、ページURLと掲示済みQRコードを変えずに更新できます。
3. `index.html` の「2026年11月版」を新しい年月に書き換えます。
4. `index.html` 内の `v=202611` を新しい年月の値に変えてPDFのキャッシュを更新します。
5. GitHubに変更を保存し、公開ページとPDFが更新されたことを確認します。端末に古いPDFが残る場合はページを再読み込みしてください。

## 公開前の確認

添付PDFはA3横向き1ページです。施工体系図には氏名、施工会社名、担当者・連絡先や事業者情報が含まれる場合があります。現場掲示のために公開する資料として、工事発注者・元請会社など必要な承認と公開範囲を必ず確認してください。QRコードからアクセスできる人は誰でもPDFを閲覧・保存でき、URLを知る人以外に限定する仕組みはありません。

PDFを差し替えた後は、公開ページの表示年月とPDFの年月が一致することを確認してください。
